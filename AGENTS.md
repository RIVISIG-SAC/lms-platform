## Cómo usar los agentes

Claude puede:

- Seleccionar automáticamente el agente según la tarea
- Combinar múltiples agentes
- Aplicar mejores prácticas específicas

También puedes invocarlos manualmente:

Ejemplo:

@prisma-client crea una query optimizada  
@shadcn crea un componente modal accesible  
@nodejs-backend-patterns estructura este endpoint  

---

## Regla clave

Siempre usar el agente más especializado disponible para cada tarea.
